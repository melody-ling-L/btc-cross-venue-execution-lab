# 第一天理解一笔跨交易所交易

预计 60 至 90 分钟。先手算，再解释，最后用参考程序核对。今天先提交前 3 题即可。

所有价格和费率均为合成教学数字，不是当前行情或实际账户费率。只做现货；每笔手续费以 USDT 从成交账户扣除。不考虑网络、延迟、冲击、退出成本或转账；假设当前报价有足够数量供本题成交。

## 四个词

- **bid 买价**：市场里有人愿意买入的价格，你主动卖出时打到这一侧。
- **ask 卖价**：市场里有人愿意卖出的价格，你主动买入时打到这一侧。
- **基点 bp**：1 bp = 0.01%，10 bp = 0.1% = 0.001。
- **敞口**：持仓价值对价格变化的敏感程度。今天先用持有的 BTC 数量表示 BTC 价格敞口。

## 已知条件

| 项目 | A 所 | B 所 |
| --- | --- | --- |
| 初始 USDT | 10,000 | 0 |
| 初始 BTC | 0 | 0.1 |
| bid | 99,990 | 100,150 |
| ask | 100,000 | 100,160 |
| 每笔手续费率 | 0.1% | 0.1% |

操作：A 主动买入 0.05 BTC，同时尝试在 B 主动卖出 0.05 BTC。第 1 至 5 题先假设双腿都成功。

开始和结束的统一估值价格均为 100,000 USDT/BTC。两所 BTC 与 USDT 分别记账，不能因为总余额够就忽略某一所余额不足。

## 请自己回答

1. A 买入用 bid 还是 ask？买入金额多少，手续费多少？
2. A 成交后还剩多少 USDT，持有多少 BTC？写出现金计算过程。
3. B 卖出用 bid 还是 ask？卖出金额多少，手续费多少？
4. B 成交后 USDT 和 BTC 分别是多少？
5. 合计 USDT、BTC 和统一估值下的总资产分别是多少？与保持初始库存不动相比，赚了还是亏了？正价差为什么不足以保证净收益？
6. 如果 A 买入成功，B 明确拒单，合计 BTC 比交易前多多少？按共同估值此时损益是多少？这个数能否代表之后的最大损失？
7. 如果 B 的响应只是超时，能否直接认定它没有成交并无限重试？你还需要什么证据？

## 可使用的公式

```text
成交金额 = 成交价格 × BTC 数量
手续费 = 成交金额 × 手续费率
买入后 USDT = 原 USDT − 成交金额 − 手续费
卖出后 USDT = 原 USDT + 成交金额 − 手续费
总资产 = 两所 USDT 之和 + 两所 BTC 之和 × 统一估值价格
保持初始库存的期末权益 = 初始 USDT 合计 + 初始 BTC 合计 × 同一期末估值价格
执行贡献 = 实际期末权益 − 保持初始库存的期末权益
```

本题期初与期末估值相同，执行贡献与相对期初权益的损益相同。以后估值变化时，要分别看绝对盈亏和相对持有基准的差额。

## 算完再核对

参考代码位于 `../examples/ledger_reference.py`。在项目目录运行 `python3 examples/ledger_reference.py --scenario both_filled`。单腿案例使用 `--scenario buy_only`。

参考程序只知道你指定的成交结果，不会判断真实订单是否成交。未知订单状态、真实盘口、报价时序与退出成本是后续项目要实现的内容。
